# Chapter 1: Introduction to Strings
===============================================================================

## Introduction

String ek ordered sequence of characters hota hai. Java me String immutable hoti
hai, matlab once created uska content directly change nahi hota.

Hinglish idea:
String ko letters ki train samjho. Har coach ek character hai, aur order change
hota hai to meaning bhi change ho jata hai.

## Pattern Recognition

String use karo jab problem me ye clues aaye:
- word, text, sentence, line
- palindrome, anagram, reverse
- prefix, suffix, substring
- compare, search, replace
- formatting, trimming, parsing

## Trigger Words

- `reverse` -> two pointers or StringBuilder
- `count` -> frequency array or HashMap
- `search` -> pattern matching or sliding window
- `prefix` -> startsWith or trie
- `palindrome` -> left-right scan
- `anagram` -> frequency compare

## Brute Force

Har step me string `+` se join karna.

```java
String ans = "";
for (int i = 0; i < s.length(); i++) {
    ans = ans + s.charAt(i);
}
```

Time: O(n^2), Space: O(n)

Why rejected:
Har concat naya object banata hai, isliye repeated copying hoti hai.

## Observation

Jab output grow hota hai, `StringBuilder` better choice hoti hai.

## Core Intuition

String = fixed order ka character array jaisa structure.
Direct modification ke liye `char[]` ya `StringBuilder` socho.

## Visualization

```text
Index:  0  1  2  3  4
Value:  r  a  c  e  c
```

## Dry Run

`racecar`:
- left = r, right = r -> match
- left = a, right = a -> match
- left = c, right = c -> match
- middle pe stop

## Java Templates

```java
public class Main {
    public static void main(String[] args) {
        String s = "interview";
        StringBuilder sb = new StringBuilder();

        for (int i = 0; i < s.length(); i++) {
            sb.append(s.charAt(i));
        }

        System.out.println(sb.toString());
    }
}
```

## Complexity Analysis

- charAt access: O(1)
- traversal: O(n)
- concat in loop: O(n^2)
- StringBuilder append: amortized O(1)

## Common Mistakes

- `==` se String compare karna
- repeated `+` in loop
- case handling ignore karna
- spaces and punctuation forget karna

## Interview Follow-up Questions

- String immutable kyu hai?
- `StringBuilder` aur `StringBuffer` me difference kya hai?
- `equals()` aur `==` me difference kya hai?

## Easy Problems

- print characters
- reverse string
- count vowels
- check palindrome

## Medium Problems

- anagram check
- first unique character
- longest substring without repeat

## Hard Problems

- minimum window substring
- KMP search
- edit distance

## Similar Questions

- array traversal
- frequency count
- two pointers
- sliding window

## Pattern Flowchart

```text
String question
    |
    +-- build output? -> StringBuilder
    +-- compare ends? -> two pointers
    +-- count chars? -> freq array / HashMap
    +-- search pattern? -> sliding window / KMP / trie
```

## Memory Tricks

- immutable
- ordered
- length fixed for same object
- use builder for mutation

## One Page Revision Sheet

String = characters ka ordered, immutable sequence. Interview me pehle clue
pakdo: compare, count, search, build, or search-in-text.

# Chapter 3: String Fundamentals and Java Memory Model
===============================================================================

## Introduction

Java me String immutable hoti hai, aur ye behavior interview me baar-baar aata
hai. String pool, heap object, equals, hashCode, aur builder ka relation samajhna
important hai.

Hinglish:
String ko safe text block samjho, jise direct edit nahi kar sakte.

## Pattern Recognition

Ye chapter tab use karo jab problem me:
- `==` vs `equals()`
- repeated concatenation
- object creation
- memory efficiency
- mutation required ho

## Trigger Words

- `modify` -> StringBuilder
- `thread-safe` -> StringBuffer
- `compare` -> equals
- `same reference` -> `==`
- `reuse text` -> string pool

## Brute Force

Har change ke liye nayi String create karna.

```java
String s = "a";
s = s + "b";
s = s + "c";
```

Time: inefficient for loops.

## Observation

Immutable String security aur sharing ke liye useful hai. Jahan edit chahiye,
wahan builder ya char array better hai.

## Core Intuition

Two strings same text ke saath bhi different objects ho sakte hain.

```text
"java"  --> pool reference
new String("java") --> new heap object
```

## Visualization

```text
String pool:   "java"  "code"
Heap:          new String("java")
```

## Dry Run

```java
String a = "cat";
String b = "cat";
String c = new String("cat");
```

- `a == b` -> true
- `a == c` -> false
- `a.equals(c)` -> true

## Java Templates

```java
public class Main {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder();
        sb.append("inter");
        sb.append("view");
        String s = sb.toString();
        System.out.println(s);
    }
}
```

## Complexity Analysis

- `equals()` -> O(n)
- `==` -> O(1)
- concat in loop -> O(n^2)
- builder append -> amortized O(1)

## Common Mistakes

- `==` se content compare karna
- immutability ko ignore karna
- `StringBuffer` ko always necessary samajhna
- builder ko `toString()` ke bina print karna

## Interview Follow-up Questions

- String pool kya hai?
- immutable objects ka fayda kya hai?
- `StringBuilder` thread-safe kyu nahi hota?

## Easy Problems

- compare two strings
- concatenate strings
- uppercase/lowercase convert

## Medium Problems

- repeated concatenation fix
- reverse string with builder
- format a sentence

## Hard Problems

- very large text processing
- streaming style text build

## Similar Questions

- object identity
- deep vs shallow compare
- mutable vs immutable data

## Pattern Flowchart

```text
Need change text?
    -> yes -> StringBuilder
Need compare content?
    -> yes -> equals()
Need compare reference?
    -> yes -> ==
```

## Memory Tricks

- String = immutable
- Builder = mutable
- Buffer = mutable + synchronized
- equals = content
- == = reference

## One Page Revision Sheet

Text compare karna ho to `equals()`. Text build karna ho to `StringBuilder`.
Mutability ka question aate hi immutability, pool, and references yaad karo.

# Chapter 4: Character Traversal and Frequency Counting
===============================================================================

## Introduction

Bahut saare string problems ka base hai character traversal. Pehle har char dekh
lo, phir frequency ya position se answer nikaalo.

Hinglish:
Letters ko ek-ek karke scan karo, jaise attendance le rahe ho.

## Pattern Recognition

Use this when question me:
- count vowels / consonants
- first non-repeating character
- repeated character
- frequency based comparison
- duplicates in text

## Trigger Words

- `count`
- `frequency`
- `occurrence`
- `duplicate`
- `unique`
- `first repeated`

## Brute Force

Har character ke liye poore string me scan.

```java
for (int i = 0; i < s.length(); i++) {
    int count = 0;
    for (int j = 0; j < s.length(); j++) {
        if (s.charAt(i) == s.charAt(j)) {
            count++;
        }
    }
}
```

Time: O(n^2)

## Observation

One pass me frequency store karo, second pass me answer nikaalo.

## Core Intuition

Frequency array ya HashMap ek register ki tarah kaam karta hai.

## Visualization

```text
banana
b -> 1
a -> 3
n -> 2
```

## Dry Run

`banana`:
- b -> 1
- a -> 1
- n -> 1
- a -> 2
- n -> 2
- a -> 3

## Java Templates

```java
public class Main {
    public static void main(String[] args) {
        String s = "banana";
        int[] freq = new int[26];

        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (ch >= 'a' && ch <= 'z') {
                freq[ch - 'a']++;
            }
        }

        System.out.println(freq['a' - 'a']);
    }
}
```

## Complexity Analysis

- traversal: O(n)
- frequency array: O(1) extra for English letters
- HashMap: O(k) space for distinct chars

## Common Mistakes

- uppercase ignore karna
- spaces and symbols count karna bhool jana
- second pass skip karna
- `char[]` vs `String` indexing confuse karna

## Interview Follow-up Questions

- first unique char kaise nikaaloge?
- vowel count case-insensitive kaise karoge?
- unicode text handle kaise karoge?

## Easy Problems

- count characters
- count vowels
- find duplicates

## Medium Problems

- first non-repeating char
- common characters in two strings
- isomorphic style frequency check

## Hard Problems

- frequency based window problems
- very large alphabet handling

## Similar Questions

- hashmap counting
- array frequency
- sorting by frequency

## Pattern Flowchart

```text
Count keyword?
    -> yes -> freq array / HashMap
Unique keyword?
    -> yes -> one pass count + second pass check
Duplicate keyword?
    -> yes -> seen set or freq map
```

## Memory Tricks

- count first, decide later
- lowercase -> 26
- general text -> map

## One Page Revision Sheet

Count problems me direct brute force avoid karo. Frequency register banao, phir
answer derive karo.

# Chapter 5: Palindrome Pattern
===============================================================================

## Introduction

Palindrome ka matlab hai aisa text jo left se right aur right se left same lage.
Interview me ye pattern two pointers ka classic use hai.

Hinglish:
Palindrome ko mirror image samjho.

## Pattern Recognition

Use when question says:
- palindrome
- reverse equal
- symmetric
- valid after removing symbols
- near palindrome

## Trigger Words

- `mirror`
- `reverse`
- `same from both ends`
- `center`
- `symmetry`

## Brute Force

Reverse banao aur compare karo.

```java
String rev = new StringBuilder(s).reverse().toString();
boolean ok = s.equals(rev);
```

Time: O(n), Space: O(n)

## Observation

Two pointers se extra space bach sakta hai. Agar ignore rules hain to helper
checks use karo.

## Core Intuition

Left aur right ko ek saath move karo. Jahan mismatch mile, wahan answer false.

## Visualization

```text
left ->  r  a  c  e  c  a  r  <- right
```

## Dry Run

`level`:
- l vs l match
- e vs e match
- v middle pe stop

## Java Templates

```java
public class Main {
    static boolean isPalindrome(String s) {
        int l = 0, r = s.length() - 1;
        while (l < r) {
            if (s.charAt(l) != s.charAt(r)) return false;
            l++;
            r--;
        }
        return true;
    }
}
```

## Complexity Analysis

- two pointers: O(n)
- reverse compare: O(n)
- extra space: O(1) for pointers

## Common Mistakes

- case conversion skip karna
- spaces/punctuation handle na karna
- middle character ko mismatch maanna

## Interview Follow-up Questions

- one deletion allowed ho to?

## Easy Problems

- check palindrome
- reverse string
- palindrome number like text check

## Medium Problems

- valid palindrome with cleanup
- near palindrome
- longest palindromic prefix

## Hard Problems

- longest palindromic substring
- palindrome pairs

## Similar Questions

- two pointer scan
- symmetry problems
- reverse and compare

## Pattern Flowchart

```text
Palindrome clue
    -> clean text? -> normalize first
    -> ends compare? -> two pointers
    -> build reverse? -> StringBuilder
```

## Memory Tricks

- left-right
- mirror
- center stop
- one mismatch may matter in variant problems

# Chapter 6: Anagram and Permutation Pattern
===============================================================================

## Introduction

Anagram me characters same hote hain, order different ho sakta hai. Permutation
based thinking strings me bohot common hai.

Hinglish:
Same alphabets, different arrangement.

## Pattern Recognition

Use when question says:
- anagram
- permutation
- rearrangement
- same frequency
- group similar words

## Trigger Words

- `same letters`
- `different order`
- `rearrange`
- `group`
- `permute`

## Brute Force

Dono strings sort karo aur compare karo.

```java
char[] a = s1.toCharArray();
char[] b = s2.toCharArray();
Arrays.sort(a);
Arrays.sort(b);
boolean ok = Arrays.equals(a, b);
```

Time: O(n log n)

## Observation

Frequency compare se O(n) me kaam ho jata hai.

## Core Intuition

Anagram ka essence order nahi, count hai.

## Visualization

```text
listen -> s i l e n t
silent -> s i l e n t
```

## Dry Run

`listen` and `silent`:
- all letters same count
- result true

## Java Templates

```java
public class Main {
    static boolean isAnagram(String a, String b) {
        if (a.length() != b.length()) return false;
        int[] freq = new int[26];

        for (int i = 0; i < a.length(); i++) {
            freq[a.charAt(i) - 'a']++;
            freq[b.charAt(i) - 'a']--;
        }

        for (int x : freq) {
            if (x != 0) return false;
        }
        return true;
    }
}
```

## Complexity Analysis

- sort approach: O(n log n)
- count approach: O(n)
- space: O(1) for 26 letters

## Common Mistakes

- length check skip karna
- uppercase/lowercase mismatch
- unicode text me 26 array use kar dena

## Interview Follow-up Questions

- group anagrams kaise karoge?
- anagram window kaise find karoge?
- permutation in string ka idea?

## Easy Problems

- valid anagram
- check permutation
- common character count

## Medium Problems

- group anagrams
- find all anagrams in text

## Hard Problems

- minimum swaps for anagram-like rearrangement
- large alphabet grouping

## Similar Questions

- frequency counting
- sorting by key
- hashmap grouping

## Pattern Flowchart

```text
Same letters?
    -> yes -> count compare
Group similar words?
    -> yes -> sort key / freq key in HashMap
Window me match chahiye?
    -> yes -> sliding window + freq diff
```

## Memory Tricks

- order not important
- count important
- length first

solution rakho.

# Chapter 7: Two Pointer Pattern on Strings
===============================================================================

## Introduction

Two pointers strings me tab use hote hain jab left aur right se compare ya scan
karna ho. Ye palindrome, reverse, cleanup, and in-place transform me kaam aata
hai.

Hinglish:
Ek pointer start se, ek pointer end se.

## Pattern Recognition

Use when:
- ends compare karne hain
- in-place modify karna hai
- filtered characters handle karne hain
- opposite direction se scan useful hai

## Trigger Words

- `left`
- `right`
- `end points`
- `pair`
- `reverse`
- `skip invalid`

## Brute Force

Har character ko new string me copy karo.

## Observation

Two pointers me extra array banane ki zarurat nahi padti.

## Core Intuition

Left pointer valid char dhoondhe, right pointer valid char dhoondhe, then
process and move.

## Visualization

```text
  l                 r
  v                 v
  [  a  b  c  d  e  ]
```

## Dry Run

Reverse vowels:
- left pe vowel mile to right vowel dhoondo
- swap karo
- move inward

## Java Templates

```java
public class Main {
    static String reverseVowels(String s) {
        char[] arr = s.toCharArray();
        int l = 0, r = arr.length - 1;

        while (l < r) {
            while (l < r && !isVowel(arr[l])) l++;
            while (l < r && !isVowel(arr[r])) r--;
            char temp = arr[l];
            arr[l] = arr[r];
            arr[r] = temp;
            l++;
            r--;
        }
        return new String(arr);
    }

    static boolean isVowel(char ch) {
        return "aeiouAEIOU".indexOf(ch) >= 0;
    }
}
```

## Complexity Analysis

- scanning: O(n)
- in-place swap: O(1) extra

## Common Mistakes

- invalid chars skip karna bhool jana
- pointers ko move na karna
- same pointer pe swap karna

## Interview Follow-up Questions

- reverse words using pointers?
- remove duplicates using slow-fast?
- valid palindrome with cleanup?

## Easy Problems

- reverse string
- reverse vowels
- compare two strings

## Medium Problems

- remove duplicates in sorted string
- backspace string compare
- compress string

## Hard Problems

- in-place string transformation
- custom cleanup with multiple conditions

## Similar Questions

- array two pointers
- linked list slow-fast
- partitioning style scans

## Pattern Flowchart

```text
Ends matter? -> two pointers
Need cleanup + compare? -> two pointers + skip logic
Need in-place transform? -> two pointers on char array
```

## Memory Tricks

- left-right
- skip invalid
- swap only when both valid

## One Page Revision Sheet

# Chapter 8: Sliding Window Pattern on Strings
===============================================================================

## Introduction

Sliding window strings me sabse powerful pattern hai. Jahan contiguous substring
aur optimization dono aate hain, window socho.

Hinglish:
Window ko expand karo, problem aaye to shrink karo.

## Pattern Recognition

Use when:
- longest substring
- minimum window
- at most K distinct
- no repeat
- substring with condition

## Trigger Words

- `subarray` / `substring`
- `contiguous`
- `longest`
- `minimum`
- `at most K`
- `without repeating`

## Brute Force

Har substring check karo.

```java
for (int i = 0; i < s.length(); i++) {
    for (int j = i; j < s.length(); j++) {
        String sub = s.substring(i, j + 1);
    }
}
```

Time: O(n^2) or worse depending on check

## Observation

Window me answer incremental banta hai. Har step pe same work repeat nahi karna.

## Core Intuition

Right pointer se window grow, left pointer se window repair.

## Visualization

```text
string: a b c a b c b b
window: [   l     r   ]
```

## Dry Run

`abcabcbb`:
- expand until duplicate
- duplicate aaya to left move
- best length update

## Java Templates

```java
public class Main {
    static int longestUniqueSubstring(String s) {
        int[] freq = new int[128];
        int l = 0, best = 0;

        for (int r = 0; r < s.length(); r++) {
            freq[s.charAt(r)]++;
            while (freq[s.charAt(r)] > 1) {
                freq[s.charAt(l)]--;
                l++;
            }
            best = Math.max(best, r - l + 1);
        }
        return best;
    }
}
```

## Complexity Analysis

- each pointer moves at most n times
- time: O(n)
- space: O(1) for fixed ASCII, O(k) for map

## Common Mistakes

- while ki jagah if use karna
- left update ke time count miss karna
- answer update late karna

## Interview Follow-up Questions

- min window substring ka shrink rule?
- at most K distinct ka template?
- exactly K kaise nikalo?

## Easy Problems

- longest unique substring
- count substrings with a condition

## Medium Problems

- minimum window substring
- longest substring with K distinct
- character replacement

## Hard Problems

- minimum covering window
- multiple constraints window

## Similar Questions

- prefix sum window
- two pointer count
- hashmap + window

## Pattern Flowchart

```text
Contiguous substring?
    -> yes -> sliding window
Need longest / minimum?
    -> yes -> expand + shrink
Need frequency inside window?
    -> yes -> map / array
```

## Memory Tricks

- expand right
- repair left
- update answer after repair

## One Page Revision Sheet

Sliding window ka hero rule: right se grow, left se fix. Jab contiguous answer
aur repeated checking ho, window best friend hai.

# Chapter 9: Substring, Subsequence, Prefix, and Suffix

## Introduction

Substring aur subsequence me difference clear hona chahiye. Contiguous nahi to
substring nahi, bas subsequence. Prefix aur suffix string logic ka base hai.

Hinglish:
Substring = chipka hua block. Subsequence = selected characters, gap allowed.

## Pattern Recognition

Use when:
- prefix check
- suffix check
- common prefix
- substring search
- subsequence validation

## Trigger Words

- `starts with`
- `ends with`
- `common prefix`
- `partial order`
- `skip characters`

## Brute Force

Har prefix ya substring compare karo.

## Observation

Prefix/suffix problems me direct library methods kabhi enough hote hain, but
core logic samajhna more important hai.

## Core Intuition

Prefix fixed start se banta hai.
Suffix fixed end se banta hai.
Subsequence me pointers selectively move karte hain.

## Visualization

```text
string:  p r o g r a m
prefix:  p r o
suffix:                  a m
subseq:   p   o     a
```

## Dry Run

`ace` subsequence of `abcde`:
- a found
- c found
- e found
- success

## Java Templates

```java
public class Main {
    static boolean isPrefix(String s, String pref) {
        if (pref.length() > s.length()) return false;
        for (int i = 0; i < pref.length(); i++) {
            if (s.charAt(i) != pref.charAt(i)) return false;
        }
        return true;
    }
}
```

## Complexity Analysis

- prefix/suffix compare: O(k)
- subsequence check: O(n)
- naive substring search: O(n * m)

## Common Mistakes

- substring aur subsequence ko same samajhna
- length compare skip karna
- prefix ke liye full scan kar dena

## Similar Questions

- array subarray vs subsequence

## Pattern Flowchart

```text
Starts / ends? -> prefix / suffix compare
Skip allowed?   -> subsequence
Contiguous?     -> substring
```

## Memory Tricks

- prefix = front

# Chapter 10: StringBuilder, Compression, and Mutation
===============================================================================

## Introduction

Jab string build, compress, insert, delete, reverse ya mutate karni ho, tab
StringBuilder ka use hota hai. Plain String se ye kaafi fast hota hai.

Hinglish:
Jo kaam baar-baar change kare, uske liye mutable tool chahiye.

## Pattern Recognition

Use when:
- output construct karna hai
- repeated append hai
- compression chahiye
- reverse words / reverse chunks
- insert/delete operations hain

## Trigger Words

- `build`
- `append`
- `compress`
- `replace`
- `delete`
- `reverse`

## Brute Force

Har append pe naya string banana.

## Observation

Builder me edit cheap hoti hai. Final output ke liye `toString()` use karo.

## Core Intuition

StringBuilder = mutable buffer.

## Visualization

```text
builder: [ i ][ n ][ t ][ e ][ r ]
```

## Dry Run

`aaabbc` compression:
- a count 3
- b count 2
- c count 1

## Java Templates

```java
public class Main {
    static String compress(String s) {
        StringBuilder sb = new StringBuilder();
        int count = 1;

        for (int i = 1; i <= s.length(); i++) {
            if (i < s.length() && s.charAt(i) == s.charAt(i - 1)) {
                count++;
            } else {
                sb.append(s.charAt(i - 1));
                if (count > 1) sb.append(count);
                count = 1;
            }
        }
        return sb.toString();
    }
}
```

## Complexity Analysis

- append: amortized O(1)
- complete build: O(n)
- extra space: O(n) for result

## Common Mistakes

- loop me `+=` use karna
- `toString()` bhool jana
- count reset miss karna

## Interview Follow-up Questions

- `StringBuilder` vs `StringBuffer`?
- string compression me edge cases kya hain?
- reverse words in-place kaise karoge?

## Easy Problems

- reverse string
- build sentence
- compress repeated chars

## Medium Problems

- run-length encoding
- reverse words
- remove extra spaces

## Hard Problems

- in-place compression
- custom normalization pipeline

## Similar Questions

- mutable buffers
- array compaction
- two pointer cleanup

## Pattern Flowchart

```text
Need output by pieces?
    -> yes -> StringBuilder
Need mutate in place?
    -> yes -> char[] / builder
Need compression?
    -> yes -> builder + count
```

## Memory Tricks

- build with builder
- mutate with builder
- finalize with `toString()`

## Brute Force

Every start index pe pattern compare karo.

```java
for (int i = 0; i + m <= n; i++) {
    int j = 0;
    while (j < m && text.charAt(i + j) == pat.charAt(j)) j++;
}
```

## Observation

Mismatch ke baad previous matched prefix ka kuch part reuse ho sakta hai. KMP
is reuse ko formalize karta hai.

## Core Intuition

LPS = longest prefix which is also suffix.

```text
pattern: a b a b a c
prefix : a b a b a
suffix :     a b a b a
```

## Visualization

```text
text:    a b a b a b c
pattern:     a b a c
```

## Dry Run

Mismatch aane pe pattern ko start se nahi, LPS based shifted position pe le jao.

## Java Templates

```java
public class Main {
    static int[] buildLPS(String p) {
        int[] lps = new int[p.length()];
        int len = 0, i = 1;
        while (i < p.length()) {
            if (p.charAt(i) == p.charAt(len)) {
                lps[i++] = ++len;
            } else if (len > 0) {
                len = lps[len - 1];
            } else {
                lps[i++] = 0;
            }
        }
        return lps;
    }
}
```

## Complexity Analysis

- naive search: O(n * m)
- KMP: O(n + m)
- Trie insert/search: O(length of word)

## Common Mistakes

- LPS ko prefix only samajhna
- mismatch pe restart from zero
- trie me child array null check bhool jana

- word break me trie ka role kya hai?

## Java Templates

```java
public class Main {
    static void dfs(int idx, StringBuilder path, String s) {
        if (idx == s.length()) {
            System.out.println(path.toString());
            return;
        }

        path.append(s.charAt(idx));
        dfs(idx + 1, path, s);
        path.deleteCharAt(path.length() - 1);

        dfs(idx + 1, path, s);
    }
}
```

# Chapter 14: Dynamic Programming on Strings
===============================================================================

## Introduction

String DP tab aata hai jab answer subproblems ke table se build hota hai. LCS,
edit distance, distinct subsequences aur interleaving strings classic examples
hain.

## Pattern Recognition

Use when the question says:
- insert, delete, replace
- common subsequence
- minimum operations
- number of ways

## Core Intuition

`dp[i][j]` usually prefix `i` and prefix `j` ke relation ko represent karta hai.
Base cases aur transitions sabse important hote hain.

## Brute Force

Recursive solution without memoization same states ko baar-baar solve karega.

## Optimal Approach

2D table banao, transitions define karo, then space optimize karna possible hai.

## Dry Run

LCS me:
- match -> diagonal + 1
- mismatch -> top ya left ka max

## Java Template

```java
public class StringDP {
    public static int lcs(String a, String b) {
        int[][] dp = new int[a.length() + 1][b.length() + 1];
        for (int i = 1; i <= a.length(); i++) {
            for (int j = 1; j <= b.length(); j++) {
                if (a.charAt(i - 1) == b.charAt(j - 1)) dp[i][j] = dp[i - 1][j - 1] + 1;
                else dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
        return dp[a.length()][b.length()];
    }
}
```

## Complexity Analysis

- Time: O(n*m)
- Space: O(n*m), sometimes O(min(n, m))

## Common Mistakes

- index shift galat karna
- base cases skip karna
- state meaning unclear rakhna

## One Page Revision Sheet

String DP = relation table + transition logic + memoization mindset.

## Optimal Approach

Sorted key, frequency key, ya trie key bana ke grouping karo.

## Java Template

```java
import java.util.*;

public class GroupAnagramsIntro {
    public static List<List<String>> group(String[] words) {
        Map<String, List<String>> map = new HashMap<>();
        for (String w : words) {
            char[] arr = w.toCharArray();
            Arrays.sort(arr);
            String key = new String(arr);
            map.computeIfAbsent(key, k -> new ArrayList<>()).add(w);
        }
        return new ArrayList<>(map.values());
    }
}
```
